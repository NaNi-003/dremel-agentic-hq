# Dremel Phase 5: Maya Brief in the Dashboard

The dashboard now displays the Maya brief created for the latest approved opportunity instead of calling Gemini directly.

```text
YouTube pipeline -> Carl approval -> Maya brief -> dashboard
```

Select the approved trend and click **Open Content Brief**. The dashboard shows Maya's rationale, audience, tone, hook, YouTube Short concept, key beats, thumbnail direction, and call to action. The brief can still be downloaded as a text file.

If the latest run has not yet passed through Carl and Maya, the dashboard simply reports that no Maya brief is available for that trend.
